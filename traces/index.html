One delay.
Three behaviours.

The controls stay familiar while each mode changes what the repeats are trying to do. The emphasis is movement, colour and musical instability rather than adding another conventional delay to the folder.

01 / afterimage

echoes become memories

Afterimage softens and ages successive repeats so the delay gradually feels less like a copy and more like a recollection.

  • Memory changes the colour of the feedback path.
  • Age introduces soft saturation, quantisation and flutter.
  • Useful for washed pads, unstable melodic fragments and dub-like tails that slowly lose certainty.
02 / tideline

let the rhythm breathe

Tideline makes the wet signal rise and retreat in a tempo-related cycle. It can feel like a delay breathing around the source rather than sitting on top of it.

  • Tide sets the depth of the rolling wet-level movement.
  • Tempo-synced cycles keep the motion connected to the track.
  • Especially effective on ambient pulses, guitars, sparse percussion and evolving synth parts.
03 / lantern

patterns of light

Lantern applies an eight-step accent and omission pattern with stereo movement. Repeats appear, disappear and shift position like points of light across a scene.

  • Light controls the amount of rhythmic patterning.
  • Pattern selection changes the accent/omission behaviour.
  • Ideal when a static echo needs animation without becoming a full sequencer.

Beta installation notes.

These builds are intentionally distributed for testing before code-signing and notarisation are finalised. Your operating system may therefore display a security warning even when the file was downloaded directly from Slowfield Audio.

macOS beta

The current Mac installer is an unsigned/not-yet-notarised beta. macOS may say the package cannot be opened because Apple cannot check it for malicious software.

After downloading from this site, Control-click the package and choose Open, or use System Settings → Privacy & Security → Open Anyway if macOS blocks the first launch.

The installer places AU and VST3 builds in the standard system plug-in locations.

Windows beta

Windows SmartScreen may show “Windows protected your PC” because the beta installer is not yet code-signed and has not built reputation with Microsoft.

If you downloaded it directly from this page, choose More info → Run anyway. The installer places the VST3 in the standard C:\Program Files\Common Files\VST3 location.

Do not bypass a warning for a copy obtained from an unknown third-party source.
