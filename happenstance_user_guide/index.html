CONTROLLED UNPREDICTABILITY

SAFE ↔ WILD

SAFE

Subtle, rhythm-aware movement. Good for drums and material whose identity should stay obvious.

50–70%

A broad creative range for everyday exploration.

WILD

More radical slicing, spacing and mutation.

Under the hood

Transient sensitivity helps rhythmic material retain useful attack information. At high WILD values the engine is governed so adventurous processing stays more musically coherent.

PHRASE MEMORY

A · B · C · D

A

Tap empty: capture the current phrase.

B

Tap filled: recall it.

C

Shift + tap: replace it.

D

Drag: move captured WAV material back to your DAW.

Tip: Clear Memory when changing to a completely different source so the next experiment starts cleanly.
QUICK RECIPES

Three starting ideas

Gentle piano

WILD 25–40%. Favour Ghost/Cloud. Keep when the motion feels musical.

Drum remix

WILD 40–65%. Capture phrase memory, then explore Rearrange + Negative Space.

Ambient accident

WILD 65–85%. Use sustained material with Cloud, Shimmer and Ghost, then save a successful direction as a Starting Point.
